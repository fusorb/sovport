# Archive

Historical records kept for reference. Nothing in here is current-facing; treat
its versions, tooling rows and "now carries" statements as snapshots of the day
they were written, not as descriptions of the present tree.

- `audits/` — dated repository audits and the remediation pass. Captured while
  each fix was in flight.
- `ecosystem-naming/` — the Facet 2.0.0 / SovPort naming migration baseline,
  findings and report. These self-declare as historical and are wrapped as
  generated sections so the naming gate tolerates their deliberate legacy-token
  references.

Current state lives in [../../SYNC.md](../../SYNC.md) and the integration plan.
